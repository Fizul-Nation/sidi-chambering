FAQ

Before you ask

Is this only for pupils already in chambers?

No. The syllabus is built to work for junior lawyers already in practice, not just pupils. We designed it to be practical and hands-on, with live exercises running through both sessions, not just a lecture.

Will this guarantee I get chambers?

No program can guarantee that. What this does is prepare you to perform once you're in.

I've already done a mooting or advocacy course. Is this different?

Yes. This covers the administration, file management, and courtroom conduct those courses don't touch.

Do I need to attend both sessions?

Ideally, yes, since your seat covers both sessions and each builds on the other. If you're only able to attend one, you'll still receive a certificate for the session you completed.

What's the refund policy?

All seats are non-refundable once payment is confirmed. We keep each cohort small so the live exercises stay personal, which means seats can't be released or refunded after registration.
